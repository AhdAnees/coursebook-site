Install Liyaa Note (about 2 minutes)

Liyaa Note isn't on the Play Store yet, so Android shows a few safety questions. They're normal. Here's what to tap.

  1. Download Liyaa Note The download starts straight away (about 87 MB, so Wi-Fi is best).
    You're inside a messaging app. Tap Open in Chrome at the top of this page first, then download there.
    If Chrome says “File might be harmful”, tap Download anyway.
  2. When the download finishes, tap Open at the bottom of the screen (or find Liyaa-Note…apk in your notifications or the Files → Downloads app).
  3. Android may say “For your security, your phone is not allowed to install unknown apps from this source.” Tap Settings, switch on Allow from this source, then tap ← back.
    This permission is only for your browser or Files app. You can switch it off again after installing.
  4. Tap Install. If you already have Liyaa Note, tap Update. Your notes stay.
    If Google Play Protect warns that the app is unknown, tap More details → Install anyway. If it offers to scan the app, you can let it scan, then install.
  5. Tap Open. Create your account (or sign in), and agree to the community rules.
  6. Come back to this page and tap I already have Liyaa Note: open my invite at the top, or in the app tap ＋ Add → Join a course and type the code --------.
    The course owner may need to approve you first. You'll see the course as soon as they do.

Something not working?

  • “App not installed”: you may have an old test copy signed differently. Uninstall Liyaa Note and install again (back up first in Profile & Settings → Backup).
  • “Signed with a different certificate”, “digest did not verify” or “package appears to be invalid”: the download was damaged, usually because it was made inside a messaging app. Delete the file, open this page in Chrome and download it again.
  • Nothing happens when tapping Open my invite: open Liyaa Note yourself and use ＋ Add → Join a course with the code above.
  • Download stops: the file is about 90 MB, so use Wi-Fi if you can.
